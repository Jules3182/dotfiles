*I figured it would be worth putting together a dedicated cheatsheet page because my set up has been expanding pretty quickly! Hopefully this makes sense, once you get a hang of the movement the rest is really just optional flair.*

> **Modifiers**
> 
> - `SUPER` = Windows / Super Key
>     
> - `CTRL + SHIFT` = Frequently used modifier combo
>     

---

# System Controls

| Keybind                 | Action                         |
| -------------------------| --------------------------------|
| `SUPER + M`             | Exit Hyprland                  |
| `SUPER + R`             | Run Reload Script              |
| `CTRL + SHIFT + INSERT` | Open Power Menu                |
| `SUPER + N`             | Open/Close Notification Center |
| `SUPER + L`             | Locks the screen               |

---

# App Launching

| Bind               | Action                           |
| --------------------| ----------------------------------|
| `CTRL + SHIFT + Q` | Open Terminal (Ghostty)          |
| `CTRL + SHIFT + E` | Open File Manager (Nautilus)     |
| `CTRL + SHIFT + Z` | Open Application Launcher (Wofi) |
| `SUPER + B`        | Open Browser (Zen)               |
| `CTRL + SHIFT + O` | Open Floating Open-webUI Session |
| `CTRL + SHIFT + 0` | Open Floating Pomodoro timer     |

# Movement

## General Movement

| Keybind                           | Action                            |
| --------------------------------- | --------------------------------- |
| `CTRL + SHIFT + Arrow Keys`       | Navigate Workspace Grid           |
| `CTRL + SHIFT + Mouse Wheel Down` | Move Up in Grid                   |
| `CTRL + SHIFT + Mouse Wheel Up`   | Move Down in Grid                 |
| `CTRL + SHIFT + Mouse Button 4`   | Move Up Workspace                 |
| `CTRL + SHIFT + Mouse Button 5`   | Move Down Workspace               |
| `CTRL + SHIFT + Left Mouse`       | Move Active Window Down Workspace |
| `CTRL + SHIFT + Right Mouse`      | Move Active Window Up Workspace   |
| `SUPER + 1-9`                     | Switch to Workspace 1-9           |
| `SUPER + 0`                       | Switch to Workspace 10            |
| `SUPER + ←`                       | Focus Window Left                 |
| `SUPER + →`                       | Focus Window Right                |
| `SUPER + ↑`                       | Focus Window Up                   |
| `SUPER + ↓`                       | Focus Window Down                 |


## Quick Nav Mode

**Use `CTRL + TAB` to Enter Quick Nav Mode**

| Keybind                        | Action            |
| ------------------------------ | ----------------- |
| `Arrow Keys`                   | Focus Windows     |
| `CTRL + Arrow Keys`            | Move Windows      |
| `ALT + Arrow Keys`             | Resize Windows    |
| `D`                            | Close Window      |
| `Q`                            | Open Terminal     |
| `E`                            | Open File Manager |
| `H`                            | Toggle Help Menu  |
| `ESC` / `ENTER` / `Left Click` | Exit Mode         |
